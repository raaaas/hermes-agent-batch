# Contributing to hermes-agent-batch

Thank you for your interest in contributing! This document provides guidelines for contributing to this project.

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Create a feature branch from `main`
4. Make your changes
5. Submit a pull request

## Development Setup

- Ensure you have access to GitHub Actions
- Understand the Hermes orchestration system and opencode agent architecture
- Review the existing workflow configurations in `.github/workflows/`

## Pull Request Process

1. Update documentation if your changes affect the public API or workflow behavior
2. Ensure your changes don't break existing agent configurations
3. Request review from maintainers before merging

## Code Style

- Follow existing code patterns in the repository
- Keep workflow files clear and well-documented
- Use meaningful commit messages

## Reporting Issues

- Use GitHub Issues to report bugs or suggest features
- Provide as much context as possible
- Include relevant logs or error messages

## Questions?

Open an issue for any questions about contributing to this project.
